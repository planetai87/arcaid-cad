# 회사 도면 표준으로 CAD 작도하기

CAD MCP로 그린 도면을 사람이 그린 도면과 똑같이 회사 표준에 맞추기 위한 작업 순서다. 회사 도면은 **레이어 색상으로 출력 선굵기(CTB)가 정해지고**, 작업자가 레이어를 임의로 만들 수 없다. 그래서 객체마다 표준 레이어를 지정하고 색·선굵기는 ByLayer로 두는 것이 핵심이다. 객체에 색을 직접 주면 출력 선굵기가 깨진다.

## 참조 문서 (필요할 때 읽기)

| 파일 | 언제 읽나 |
|---|---|
| `references/layers.md` | 작도 시작 전 항상. 표준 레이어 40개와 용도 |
| `references/annotation.md` | 문자·치수·축열 버블·레벨·실명·재료 표기·블록·도곽을 넣을 때 |
| `references/order-architectural.md` | 평면도·입면도·단면도 |
| `references/stair.md` | 계단(디딤선, 난간, 보행선, UP/DN, 화살표, 절단선)을 그릴 때 |
| `references/order-siteplan.md` | 배치도·인허가 도면 |

## 기본 전제

- 단위는 mm이고 모델 공간에 1:1로 그린다(1 = 1mm). 축척은 문자·기호·치수·도곽 크기에만 반영한다.
- 회사 축척은 **A3 기준**이다("1/100" = A3 1/100 = A1 1/50). A3 축척 분모를 **k**, **s = k/100**이라 한다.
- 매뉴얼 예시에 그려진 크기가 A3 1/100 표준값이다. 모든 문자·기호·간격 = 표준값 × s, `DIMSCALE = k/2`, `LTSCALE = k`, 도곽 배율 = s.
- 사용자가 축척을 말하지 않으면 평면·입면·단면은 1/100, 배치도는 대지 크기에 맞춰(1/200 이상) 정하고 사용자에게 알린다.
- 버블·계단 화살표·절단선·레벨 기호는 매번 그리지 않고 **템플릿 블록을 삽입**한다(`축열버블-상`, `축열버블-좌`, `계단화살표`, `계단절단선Z`, `LEV`, `입단면층레벨`). 템플릿에 있어도 쓰지 않는 블록이 있다(`annotation.md` "쓰지 않는 블록").
- 템플릿: **이 스킬 폴더의 `assets\회사표준_템플릿.dwg`**. `open_drawing`에는 절대경로가 필요하므로, 스킬을 불러올 때 표시되는 스킬 기준 디렉터리(Base directory)에 `assets\회사표준_템플릿.dwg`를 붙여 쓴다. 레이어 41개(`0` + 표준 40개, Defpoints 포함. 템플릿 표기는 `DEFPOINTS`, `pat`), 문자 스타일 `돋움`, 치수 스타일 DIM330/DIM270, 도곽 블록 `HEOarchitects_sheet` 등이 들어 있다.
- 스킬 원본은 arcaid-cad 저장소의 `skills/cad-drawing-standard`다. 템플릿을 다시 만드는 스크립트는 저장소의 `tools/template`에 있다.

아래는 묻지 말고 기본값으로 진행한다. 끝난 뒤 보고할 때 "가정한 것" 목록으로 반드시 알린다. 사용자가 고칠 수 있게 하기 위해서다.

| 항목 | 기본값 |

| 벽 두께 | RC 외벽 200, 내벽 150~200, 건식벽 100 |
| 창·문 위치 | 지정한 벽 위에서 대칭 또는 중앙 배치 |
| 단열재 | 사용자가 요청할 때만 그림 |
| 실번호·천장고 | 주어지지 않으면 생략 |
| 창호 부호 재질 | 창 `AW-n`(알루미늄), 외부 문 `SD-n`(철재), 내부 문 `WD-n`(목재) |
| 도면번호 | 사용자가 주지 않으면 `A-000`(빈칸 표시)으로 두고 알림 |
| 축척 | 평면·입면·단면 1/100, 배치도는 대지가 도곽에 들어가는 표준 축척 |

## 도구의 한계 (미리 알고 쓰기)

- `get_entity_properties`는 선·원·폴리라인 좌표와 문자 삽입점·높이만 돌려준다. 문자 폭, 치수, 블록 범위는 돌려주지 않으므로 위치는 계산으로 정한다(블록 범위는 `annotation.md` 표 참고).
- `draw_text`에는 정렬 옵션이 없고, 지정 좌표가 글자의 **좌하단**이 된다. 가운데·위쪽 맞춤이 필요한 문자는 `annotation.md`의 **entmake** 방법으로 만든다.
- `TEXT`, `DTEXT`, `MTEXT` 명령은 send_command로 쓰지 않는다. GstarCAD 화면 편집기가 열려 멈추고, 사용자가 CAD 창에서 ESC를 눌러야만 풀린다.
- `insert_block`은 레이어를 지정할 수 없고, 형상 정보를 돌려주지 않으며, 블록 속성값도 넣지 못한다. 속성이 있는 블록(축열 버블)은 send_command `-INSERT`로 넣는다.
- `draw_hatch`는 경계 **좌표 목록 하나**만 받는다. 기존 폴리라인 핸들도, 구멍(섬)도 받지 않는다.
  - 벽처럼 고리 모양인 영역은 겹치지 않는 직사각형 여러 개로 나눠 해치한다.
  - 패턴은 `SOLID`를 쓴다.
  - 성공 응답이 오면 해치가 지정한 레이어(ByLayer)로 바로 보인다. 저장·닫기·다시 열기는 필요 없다(GstarCAD는 서버가 명령행 `-HATCH`로 만든다).
  - 경계 폴리선이 같은 레이어에 함께 생긴다. 패턴 이름이 잘못되면 실패 응답이 오고 아무것도 남지 않는다.
  - GstarCAD에서는 `undo` 한 번에 해치만 취소되고 경계 폴리선은 남는다.
- `list_entities`의 블록 종류 이름은 `block_reference`다.
- 블록 속성값(버블 번호)과 치수 스타일은 MCP 도구로 확인할 수 없다. 검증된 명령 문자열을 그대로 써서 보장한다.

## 작업 흐름

### 1. 도면 열기

- **새 도면**: `open_drawing(템플릿)` 직후 바로 `save_drawing("<저장 경로>\도면명.dwg")`로 새 이름으로 저장한다. 저장 경로는 사용자가 지정한 곳이다. 지정하지 않았으면 arcaid-cad 저장소의 `output` 폴더(이 PC: `D:\worktable\python\cad mcp\CAD-MCP\output`)를 쓰고, 그 폴더가 없는 PC면 사용자에게 한 번 묻는다. 템플릿 파일 자체에 그리거나 저장하면 다음 도면부터 표준이 오염된다.
- `new_drawing`은 표준 레이어가 없는 빈 도면을 만들므로 쓰지 않는다.
- **기존 도면에 추가**: `list_layers`로 표준 레이어가 있는지 확인한다. 없는 레이어만 아래 "레이어가 없을 때" 방법으로 만든다.
- k ≠ 100이면 선종류 축척을 맞춘다: `send_command("_.LTSCALE\n<k>\n")`. 템플릿 값은 100이다.
- 블록 속성 입력을 켠다(한 번): `_.ATTDIA\n0\n`, `_.ATTREQ\n1\n`.

### 2. 도면 종류 확인, 순서 문서 읽기

평면/입면/단면이면 `order-architectural.md`, 배치도/인허가면 `order-siteplan.md`를 읽고 그 순서대로 그린다. 순서를 지키는 이유가 있다. 기준(중심선·대지경계선)이 먼저 있어야 나머지를 정확히 배치할 수 있고, 치수·문자는 형상이 확정된 뒤에 넣어야 다시 고치지 않는다.

### 3. 작도 규칙

- 모든 draw 도구 호출에 `layer`를 표준 레이어로 명시한다. **`color`와 `lineweight`는 넘기지 않는다**(ByLayer 유지).
- 블록(`insert_block`이든 `-INSERT`든)은 **현재 레이어**에 들어간다. 먼저 `set_current_layer`로 맞는 레이어로 바꾼 뒤 삽입하고, 끝나면 `0`으로 되돌린다. 레이어는 `annotation.md` 블록 표를 따른다(버블·계단화살표는 `DIM`, 절단선Z·방위표·ARR은 `SYM1`, 레벨 기호는 `LEV`, 도곽은 `TIT`, 주차는 `PAK`).
- 레이어 `0`에는 아무것도 그리지 않는다.
- 표준에 맞는 레이어가 없을 때 새 이름을 만들지 않는다. 가장 가까운 표준 레이어를 쓰고 그 판단을 사용자에게 알린다. 매뉴얼상 구분이 꼭 필요하면 팀 협의를 거쳐 기존 이름에 숫자를 붙이는 방식(예: `WAL2`)만 허용되므로, 만들기 전에 사용자에게 확인한다.
- 문자 높이, 치수, 축열, 레벨, 실명, 도곽 규칙은 `annotation.md`를 따른다.

### 4. send_command 사용 규칙 (GstarCAD에서 검증함)

- 옵션 사이는 **줄바꿈(`\n`)으로 구분**한다. 공백으로 구분하면 `-LAYER`가 입력 대기 상태로 멈춘다. 그 상태에서 보낸 명령은 전부 그 입력으로 먹혀 버린다.
- 아래 검증된 문자열은 끝까지 입력되어 스스로 끝나므로 그대로 쓴다. 옵션을 임의로 바꾸거나 줄이지 않는다.
- 명령이 반영되지 않았다면 다른 명령에 먹혔을 수 있다. `send_command("\n\n\n")`(빈 Enter 3번)를 보내면 대부분의 명령이 끝난다. 그래도 이후 명령이 계속 반영되지 않으면, 옵션 입력 도중에 멈춘 것이다. 이 경우 ESC가 필요한데 도구로 ESC 문자를 확실히 보낼 방법이 없으므로, 사용자에게 "CAD 창에서 ESC를 두 번 눌러 달라"고 요청한다.
- 검증된 명령 문자열:
  - 레이어 생성/속성: `_.-LAYER\n_M\n<이름>\n_C\n<색>\n<이름>\n_L\n<선종류>\n<이름>\n\n`
  - 치수 스타일 전환: `_.-DIMSTYLE\n_R\nDIM330\n` (전환하면 DIMSCALE이 스타일 값 50(1/100)으로 되돌아간다. DIM330·DIM270은 비주석 스타일이다. 2026-10-14 이전 템플릿으로 만든 도면은 주석 스타일·DIMSCALE 200이라 치수 문자가 2배로 나올 수 있다)
  - 치수 축척: `_.DIMSCALE\n<k/2>\n` (1/100이면 50. 반드시 스타일 전환 **뒤에** 보낸다)
  - 방금 그린 객체의 선종류 변경: `_.CHPROP\n_L\n\n_LT\nPHANTOM\n\n`
  - 속성값을 넣으며 블록 삽입: `_.-INSERT\n<블록명>\n<x>,<y>\n<s>\n<s>\n<회전>\n<속성값>\n` (속성 없는 블록은 마지막 속성값 줄을 뺀다)
    - 단, `입단면층레벨`은 X·Y 배율이 같게 고정된 블록이라 Y 배율을 묻지 않는다. 그래서 배율 줄이 하나다: `_.-INSERT\n입단면층레벨\n<x>,<y>\n<0.5·s>\n0\n<선 아래 값>\n<선 위 값>\n`. 줄 수가 하나라도 어긋나면 이후 입력이 한 칸씩 밀린다.
  - 정렬 문자: `(entmake '((0 . "TEXT") (8 . "<레이어>") (7 . "돋움") (10 x y 0.0) (11 x y 0.0) (40 . <높이>) (1 . "<문자>") (72 . 1) (73 . 2)))` (73: 2 = 중앙, 3 = 위)

### 5. 레이어가 없을 때 (기존 도면에서만)

`references/layers.md`의 색상·선종류로 위 `-LAYER` 명령을 보낸다. 다만 `create_layer` 도구는 색을 지정할 수 없으니 표준 레이어를 만들 때는 쓰지 않는다.

### 6. 마무리 표준 검사 (매번)

1. `list_entities(limit=1000)`로 모든 객체의 `layer`, `color`를 받는다.
2. 아래를 위반으로 센다.
   - 레이어가 `references/layers.md` 목록에 없음. 대소문자는 무시한다(템플릿의 `pat` = `PAT`).
   - 레이어가 `0`. 단, 도곽 등 블록 내부는 검사 대상이 아니다.
   - `color`가 256(ByLayer)이 아님.
3. 위반 객체는 고친다. 직접 고치는 도구가 없으므로 `erase_entity` 후 올바른 레이어로 다시 그린다.
4. `save_drawing`으로 저장한다.
5. 검증은 `list_entities` 결과로 한다. 눈으로 확인할 때는 `screenshot`을 쓴다. CAD 창을 앞으로 가져오지 않아 사용자의 작업을 방해하지 않고, 다른 창에 가려져 있어도 CAD 화면만 찍힌다.
6. 사용자에게 이렇게 보고한다: 저장 경로, 축척, 사용한 레이어별 객체 수, 위반 0건(또는 남은 위반과 이유), 기본 가정으로 정한 값, 표준에 없어서 판단한 부분.
