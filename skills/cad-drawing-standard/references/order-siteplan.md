# 배치도·인허가 도면 작성 순서

기본안이다(회사 협의 후 수정 가능). 배치도는 대지경계선이 모든 이격거리의 기준이므로 반드시 먼저 그린다.

| 단계 | 내용 | 레이어 |
|---|---|---|
| 1 | 대지경계선: 닫힌 폴리라인으로 그린 직후 `_.CHPROP\n_L\n\n_LT\nPHANTOM\n\n`로 이점쇄선 처리 | LIM |
| 2 | 도로 경계, 도로경계석, 인접 대지선 | LAN (인접 대지경계는 LIM) |
| 3 | 건축선, 이격거리 기준선(건축한계선 등) | LIM |
| 4 | 건물 외곽(1층 외벽선) | CON |
| 5 | 건물 작업기준점(WP) 표시 | LEV |
| 6 | 주차구획: 블록 `xi_parking_*`를 쓰거나 선으로 그림 | PAK |
| 7 | 주차 번호, 주차 관련 문자(출구·일방통행·합류주의) | PAK1 |
| 8 | 조경 | LAN |
| 9 | 포장·바닥 패턴, 영역 해치(`draw_hatch`에 패턴 이름과 축척을 준다. 이름이 잘못되면 실패 응답이 온다) | PAT / HAT1 |
| 10 | 치수: 대지 크기, 건물 크기, 대지경계선에서 건물까지 이격거리 | DIM |
| 11 | 레벨: `1FL%%P0 = EL00`, 대지 레벨 | LEV |
| 12 | 방위표(블록 `방위`) | SYM1 |
| 13 | 문자: 도로명·도로폭(`20M`), 인접 대지 지번, 면적표, 범례 | TXT / REM |
| 14 | 도곽, 표제란 | TIT / TIT1 |
| 15 | 표준 검사 후 저장 | — |

배치도 기본 가정(사용자가 정하지 않았을 때 이렇게 하고 보고):
- 대지·건물 "A x B"는 A = 동서(x), B = 남북(y)이다. 건물 크기는 **1층 외벽 바깥면** 기준이다(평면도의 '중심선 기준'은 배치도에 적용하지 않는다).
- 도로에 접한 대지경계선 = 도로경계선이다. 같은 위치에 선을 두 번 긋지 않는다. 도로 반대편 경계만 LAN에 대지 폭 + 양쪽 5000까지 긋는다. 도로경계석은 주어질 때만 그린다.
- 인접 대지경계선은 대지 모서리에서 바깥으로 3000 길이의 짧은 선(LIM)으로만 표시한다.
- 건축선은 도로경계선과 같다. 사용자가 건축선 후퇴나 건축한계선을 줄 때만 별도 선(LIM, 레이어 기본 선종류)을 긋는다. "2m 이상 이격" 같은 최소 이격은 선을 긋지 말고 치수로만 보여 준다.
- 건물 배치: 지정한 최소 이격을 지키고, 남는 여유는 도로 쪽(주차·마당)으로 둔다.
- WP: 건물 남서쪽 모서리에 반지름 150·s인 원과 십자선, 옆에 `WP` 문자(135·s), 모두 LEV.
- 주차: 도로에 직각으로 배치하고, 대지경계선에서 500 이상 띄운다. 주차 번호는 구획 **안쪽**, 진입부에서 볼 때 오른쪽에 135·s, entmake MC로 쓴다(PAK1).
- 대지 레벨, 조경, 포장은 주어질 때만 그린다.
- 면적표는 TXT 레이어에, 도곽 안 그림 영역의 오른쪽 아래에 둔다. 형식은 한 줄에 하나씩 `대지면적 : 600.00㎡ (20.00×30.00)`. 값을 모르는 항목(연면적·용적률 등)은 빼고, 뺐다고 알린다.

배치도 치수:
- 바깥 단: 대지 전체 크기(상부·좌측).
- 안쪽 단: 대지경계선 → 건물 → 대지경계선으로 이어지는 이격거리와 건물 크기(상부·좌측).
- 도로 폭: 도로 가운데쯤에 남북 방향 치수 1개.
- 간격: 기점(대지경계선 모서리·건물 모서리)이 가장 바깥에 있는 선에서 1단까지 900·s, 단 사이 400·s. DIM330, DIMSCALE = k/2, textheight 3.3.
- 이격거리가 짧아 치수 글자가 구간보다 길면 CAD가 글자를 바깥으로 뺄 수 있다. 그대로 두고 보고한다.

배치도 규칙:
- 주차 번호는 주차 진입부에서 볼 때 우측에 쓴다(매뉴얼).
- 주차구획 크기(블록 실제 크기): 일반 2500×5000, 확장 2600×5200, 경형 2000×3600, 장애인 3300×5300(표시 포함). 사용자가 다른 치수를 주면 그 값을 따른다.
- 이격거리 치수는 대지경계선에서 건물 외벽면까지 수직으로 잰다.
- 면적표(대지면적, 건축면적, 연면적, 건폐율, 용적률)는 사용자가 값을 주거나 형상에서 계산할 수 있을 때만 쓴다. 계산했다면 계산식을 함께 알린다.
- 배치도 축척(A3 기준)은 대지 크기에 맞춘다. 도곽 그림 영역(35000·s × 29700·s) 안에 들어가는 가장 큰 표준 축척(1/200, 1/300, 1/500, 1/600)을 고른다. s = k/100을 문자·기호·도곽 배율에, `LTSCALE = k`, `DIMSCALE = k/2`를 적용한다.
