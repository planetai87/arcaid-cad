# 계단 평면 표기 기준 (매뉴얼 `축렬, 계단.dwg` '계단 표기기준')

U자형(꺾임) 계단 평면 기준이다. 디딤판 간격·계단 폭·참 깊이는 **실제 설계 치수**라 축척과 관계없다. 기호(화살표, 절단선, 문자)와 기호 간격만 × s다(s = k/100).

## 레이어

| 요소 | 레이어 |
|---|---|
| 디딤판선, 난간 | CIR |
| 보행선, 화살표(`계단화살표` 블록) | DIM |
| 절단선(`계단절단선Z` 블록 + 팔 선) | SYM1 |
| UP / DN 문자 | TXT |

## 기호 (매뉴얼 예시)

- 보행선은 각 계단 폭 가운데를 지나는 선이다. 시작점에 점은 찍지 않는다(예시의 점은 크기 0.5라 출력에 안 보인다).
- 화살표는 `계단화살표` 블록이다(채운 쉐브론, 폭 305·높이 126). 진행 방향을 가리키고 절단선 바로 옆에 둔다.
- 절단선은 약 30° 사선이고, 보행선 위치에서 Z자로 꺾인다(`계단절단선Z` 블록).
- UP / DN 문자는 높이 150, 각 계단 폭 가운데, 첫 디딤선 100 아래에 위쪽 가운데(TC) 정렬로 쓴다.

## 좌표 (예시와 같은 배치: 왼쪽 계단 = DN 시작, 오른쪽 계단 = UP 시작, 위쪽이 참)

정할 값:

| 기호 | 뜻 | 기본값 |
|---|---|---|
| c | 두 계단 사이(난간) 중심 x | — |
| xL0 | 왼쪽 계단 바깥 끝 x | — |
| xR1 | 오른쪽 계단 바깥 끝 x | — |
| y0 | 첫 디딤선 y | — |
| T | 디딤판 깊이 | 270 |
| n | 디딤선 수 | 13 |
| yTop | 마지막 디딤선 = y0 + (n−1)·T | — |
| D | 참 깊이 | 계단 폭 |

계단 폭은 사용자 값을 따른다. 없으면 1200으로 하고 보고한다.

정하는 순서:
- 벽에 붙는 쪽의 바깥 끝을 벽 안쪽면으로 먼저 정한다.
- 나머지는 폭으로 계산한다: c = xR1 − 폭 − 125, xL0 = c − 125 − 폭. 왼쪽이 벽이면 반대로 계산한다.
- 벽에 붙지 않은 쪽은 계단 옆선(xL0 또는 xR1에서 y0 ~ yTop + D)을 CIR로 긋는다.
- 참 끝선(y = yTop + D, xL0 ~ xR1)이 벽이 아니면 이것도 CIR로 긋는다.

1. **디딤선 (CIR)**: i = 0…n−1, y = y0 + i·T
   - 왼쪽: (xL0, y) – (c−125, y)
   - 오른쪽: (c+125, y) – (xR1, y)
2. **난간 (CIR)**: 계단 사이 폭 250.
   - 닫힌 `draw_polyline` 하나: (c−75, y0−100) → (c−75, yTop+50) → (c+75, yTop+50) → (c+75, y0−100) → (c+125, y0−100) → (c+125, yTop+100) → (c−125, yTop+100) → (c−125, y0−100)
   - 안쪽 세로선 2개: x = c−50, c+50, y0 ~ yTop
   - 각 디딤선 높이의 짧은 선: (c−75, y)–(c−50, y), (c+50, y)–(c+75, y). 맨 위 yTop은 (c−75, yTop)–(c+75, yTop)
3. **보행선 (DIM)**: xl = (xL0 + c−125)/2, xr = (c+125 + xR1)/2, yLand = yTop + D/2
   - DN: `draw_polyline` (xl, y0) → (xl, yLand) → (xr, yLand)
   - UP: `draw_line` (xr, y0) → (xr, yLand)
4. **절단선 위치**: UP 계단(오른쪽) 위, yc = y0 + 4.87·T.
   - 4.87은 매뉴얼 예시의 절단 위치(디딤선 5번째와 6번째 사이, 6번째 쪽)를 그대로 옮긴 값이다.
   - 층고·단높이가 주어지면 바닥에서 약 1.2m 높이의 디딤선 근처로 옮겨도 된다. 옮겼으면 보고한다.
5. **절단선 (SYM1)**, 모두 × s 오프셋, 30°:
   - `set_current_layer("SYM1")` → `insert_block("계단절단선Z", (xr, yc), x_scale=s, y_scale=s)`
   - 아래 팔: `draw_line` (xr−65.6·s, yc−11.8·s) → (c−50, yc−11.8·s − (xr−65.6·s − (c−50))·tan30°)
   - 위 팔: `draw_line` (xr+65.6·s, yc+11.8·s) → (xE, yc+11.8·s + (xE − (xr+65.6·s))·tan30°)
     - 계단 바깥이 열린 공간이면 xE = xR1 + 290·s(매뉴얼 예시)
     - xR1이 벽 안쪽면이면 xE = xR1. 벽을 뚫고 나가지 않게 한다.
   - 두 팔 모두 layer="SYM1"
6. **화살표 (DIM)**: `set_current_layer("DIM")`. 두 화살표 모두 오른쪽 계단 xr 위에 둔다(매뉴얼 그대로).
   - 아래층으로 내려가는 DN 동선은 왼쪽에서 출발해 참을 돌아 오른쪽 계단의 절단선 너머(아래층으로 이어지는 부분)로 내려간다. 그래서 DN 화살표가 절단선 바로 위에서 아래를 가리킨다.
   - DN 화살표를 xl로 옮기지 않는다.
   - UP: `insert_block("계단화살표", (xr, yc−160·s), s, s, rotation_degrees=0)` (위를 가리킴, 절단선 직전)
   - DN: `insert_block("계단화살표", (xr, yc+133·s), s, s, rotation_degrees=180)` (아래를 가리킴, 절단선 직후)
7. **UP / DN 문자 (TXT)**, entmake 위쪽 가운데:
   - `(entmake '((0 . "TEXT") (8 . "TXT") (7 . "돋움") (10 xr y 0.0) (11 xr y 0.0) (40 . h) (1 . "UP") (72 . 1) (73 . 3)))`
   - y = y0 − 100·s, h = 150·s
   - DN은 x = xl로 같은 방식
8. `set_current_layer("0")`

배치가 예시와 좌우 반대(왼쪽이 UP)면 x를 c 기준으로 좌우 대칭해서 쓴다. 절단선 각도는 −30°가 되고, Z 블록은 `x_scale=−s`로 넣는다.

## 예시 수치 확인용 (1/100, 매뉴얼 원본)
