# 문자·치수·축열·기호·도곽

표는 `standards/heo-2026/`에서 생성한다. 수정은 YAML 원본과 `tools/standards/gen_references.py --write`로 한다. 작도 전 `get_standard(section=..., scale=k)`로 서버 값을 확인한다.

## 축척

<!-- arcaid:generated scale-rules -->
| 항목 | 프로파일 기준 |
|---|---|
| 표준 | `heo-2026@2026.1` |
| 단위 / 축척 기준 | mm / A3 |
| 축척 생략 시 k | 100 |
| 문자·기호·간격·도곽 배율 s | k × 0.01 |
| 비주석 치수 DIMSCALE | k × 0.5 |
| LTSCALE | k × 1 |
<!-- arcaid:end -->

k는 A3 축척 분모다. 모델 형상은 실제 mm, 문자·기호·간격·도곽에만 s를 적용한다. 비주석 치수는 `DIMSCALE = k/2`로 엔진이 만든다. 활성 도면 LTSCALE은 `check_standard`로 확인한다.

## 문자

기준 높이 × s는 엔진이 적용한다. 명세에는 `kind="text"`, `role`, `layer`, `content`, `at`, `align`을 쓴다. 실 중앙은 `MC`, 계단 UP/DN은 `TC` 정렬이다. 별도 명령을 보내지 않는다.

<!-- arcaid:generated text-heights -->
| role | 기준 높이 | 용도 | 허용 레이어 |
|---|---|---|---|
| `main_title` | 255 | 설계명, 도면명, 도면 안 MAIN TITLE | TIT1 |
| `sub_title` | 165 | 설계자명, 축척, 프로젝트번호, SUB TITLE | TIT1 |
| `general` | 135 | 도면 안 일반 문자(실명, NOTES, 기호 안 글자, 레벨) | TXT / ROM / REM / SYM / LEV |
| `small_tag` | 105 | 작은 표식 안 글자(실번호·천장고, 창호 부호) | ROM / DOR / WIN |
| `grid_bubble` | 225 | 축열 버블 번호(블록 속성) | DIM |
| `stair_updn` | 150 | 계단 UP/DN | TXT |
<!-- arcaid:end -->

특수기호는 `get_standard(section="text")`의 `special_codes`를 따른다. NOTES는 간단·명료하게 쓰고 밑줄과 불필요한 약어를 피한다. 레벨·실명·창호 부호의 내용은 사용자 요구를 따른다. 실번호·천장고가 없으면 생략하고 보고한다.

|---|---|---|

| `cen_overhang_beyond_wall_min` | 외벽 바깥면·돌출부보다 더 나가는 최소 길이 | 300 |
| `extension_offset` | CEN 끝 → 치수보조선 시작(스타일에서 자동 적용) | 150 |
| `first_row_from_cen_end` | CEN 끝 → 첫 치수선 | 900 |
| `row_gap` | 치수 단 사이 | 400 |
| `bubble_from_outer_dim` | 가장 바깥 치수선 → 버블 중심(블록에 포함) | 800 |
| `text_above_dimline` | 치수 문자 중심의 치수선 위 거리(확인용) | 132 |
<!-- arcaid:end -->

간격은 기준 간격 × s다. `get_standard(section="dimensions", scale=k)`의 `spacing_scaled`를 사용한다.

1. 같은 쪽 CEN 끝점을 한 줄로 맞추고 외벽 바깥면·돌출부보다 필요한 길이를 더 연장한다.
2. 외부 치수 기점은 CEN 끝점, 개구부·벽 치수 기점은 해당 벽면 점이다.
3. 해당 면에 있는 치수만 안쪽부터 개구부·내벽 → 주열·최외벽 → 전체 순서로 놓는다. 첫 단은 `first_row_from_cen_end`, 다음 단마다 `row_gap`을 더한다.
4. `dim`·`dim_chain`에 스타일, 기점, `direction`, `line_at`을 준다. `line_at`은 치수선의 y(x방향 치수) 또는 x(y방향 치수)다. 문자 높이를 따로 주지 않는다.
5. 버블은 block 명세의 `attribs={"축열": "X1"}`처럼 작성한다. 상부 삽입점은 축 x·가장 바깥 치수선 y, 좌측은 가장 바깥 치수선 x·축 y다. 블록에 포함된 버블 간격을 다시 더하지 않는다.
6. 세로 축선은 왼쪽부터 X열, 가로 축선은 아래부터 Y열로 번호를 준다. 평면은 상부·좌측, 입면·단면은 상부에 표기한다. 보조축열은 주축 번호에 가지 번호를 붙인다.

치수 단위는 mm이며 단위 기호·천 단위 콤마를 쓰지 않는다. 등분 표기 등 dim 명세로 표현하지 못하는 특별 표기는 미지원으로 보고한다.

## 레벨·실명·창호·재료

- 평면 레벨은 LEV 블록과 `text(role="general", layer="LEV")`를 사용한다. 실 안의 레벨은 실명 아래 MC 정렬, 입면·단면 층 레벨은 치수선 밖에 둔다.
- `입단면층레벨.attribs`에서 `SL-80`은 선 아래 레벨 값, `FL%%P0`는 선 위 층 이름이다. 입력 순서에 의존하지 않는다.
- 실명은 ROM·general·MC, 실번호/천장고는 ROM·small_tag다. 줄 간격은 [설계 가정](design-assumptions.md)을 따른다.
- 창호 부호는 재질·종류·번호를 조합하고 WIN 또는 DOR·small_tag로 작성한다. 방화 관련 요구가 주어지면 그 부호에 반영한다.
- 지시선은 TXT1 선 명세로 만들 수 있다. TXT1에는 허용 문자 role이 없어 그 레이어의 재료 문자는 미지원이다.

## 표준 블록

모두 `kind="block"`으로 작성한다. `name`, `at`, 필요 시 `rotation`·`attribs`만 넣고 레이어·배율은 엔진에 맡긴다. `get_standard`의 `insert`는 이전 삽입 방식의 호환 메타데이터다. 새 작도 경로를 고르는 기준으로 쓰지 않는다.

범위는 삽입점 원점·배율 단위·회전 없음의 형상 범위다. 속성 문자 포함 범위가 다르면 비고를 확인한다.

## 도곽·표제란

`HEOarchitects_sheet`를 block 명세로 넣는다. 그림 영역은 블록 표 비고를 따르며, 버블·치수까지 포함한 도면 범위를 그 영역 중앙에 놓는다.

표제란의 at은 도곽 좌하단 + 표의 위치 × s다. 높이는 엔진이 적용한다. 도면번호 미지정 시 표의 형식을 임시값으로 쓰고 알린다.

<!-- arcaid:generated sheet-title -->
| role | 도곽 좌하단 기준 위치 | 기준 높이 | 레이어 | 형식 |
|---|---|---|---|---|
| `drawing_name` | (37400,3671) | 300 | TIT1 | 도면명 |
| `scale` | (37400,2712) | 175 | TIT1 | SCALE   A1 : 1/<k÷2>   A3 : 1/<k> |
| `drawing_number` | (37400,1500) | 400 | TIT1 | A-000 |
<!-- arcaid:end -->

한 도곽에 여러 도면을 배치하면 각 도면 아래에 main_title·sub_title 용도의 도면명·축척을 쓴다. 전체 명세는 [명세 작성](batch-spec.md)을 참고한다.
