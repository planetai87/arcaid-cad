# 기존 설계 가정과 예시

사용자가 미정으로 둔 설계값에 적용하던 기존 가정이다. YAML의 표준 수치와 구분하며 사용자 지정값이 우선한다. 사용한 가정은 assumptions와 함께 반드시 보고한다. 프로파일 확장은 후속 작업이다.

| 미정 항목 | 기존 가정 |
|---|---|
| 평면의 가로 × 세로 | 벽 중심선 기준 |
| 벽 두께 | RC 외벽 200mm, 내벽 150~200mm, 건식벽 100mm |
| 창·문 위치 | 지정 벽 위 대칭 또는 중앙 |
| 단열재 | 요청 시만 작성 |
| 실번호·천장고 | 미제공 시 생략 |
| 창호 재질 부호 | 창 AW-n, 외부 문 SD-n, 내부 문 WD-n |
| 실명 아래 실번호/천장고 줄 간격 | 기준 200 × s |
| 평면 LEV 기호 옆 문자 위치 | 삽입점 기준 위 (250,162) × s, 아래 (250,−80) × s |

계단의 미등록 형상·배치 예시는 [계단](stair.md), 배치도의 미등록 설계·표기 가정은 [배치도](order-siteplan.md)에 모았다. 블록 범위·문자 높이·주차구획 블록 치수는 [생성표](annotation.md)의 값을 쓴다.

이 가정으로 프로파일에 없는 레이어·문자 역할 조합을 만들지는 않는다. 현재 도구가 표현하지 못하는 사항은 미지원으로 보고한다.
