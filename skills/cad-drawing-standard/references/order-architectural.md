# 평면도·입면도·단면도 작성 순서

기본안이다(회사 협의 후 수정 가능). 각 단계가 끝날 때마다 다음 단계로 넘어간다. 앞 단계 형상을 기준으로 다음 단계를 배치하기 때문이다.

## 평면도

| 단계 | 내용 | 레이어 |
|---|---|---|
| 1 | 축선(기둥 중심선, 벽체 기준선). 같은 쪽 끝을 한 줄로 맞추고, 바깥 축선에서 450·s 이상(외벽 바깥면 + 300·s 이상) 연장 (`annotation.md` 간격 체인) | CEN |
| 2 | 기둥 | CON |
| 3 | 벽체: RC는 CON, 조적·보강블록은 WAL, 건식·칸막이는 WAL1. 개구부 자리는 비워 둔다 | CON / WAL / WAL1 |
| 4 | 단열재(필요 시) | INS |
| 5 | 창호: 창·유리문·커튼월은 WIN(벽 양면선 2개 + 유리선 1개), 문·문틀은 DOR(문짝 선 + 90° 호, `annotation.md` 참고), 셔터는 SHT | WIN / DOR / SHT |
| 5-1 | 창호 부호(예: `AW-1`, `SD-1`), 높이 105·s, 개구부 바깥쪽 옆 | WIN / DOR |
| 6 | 계단: `stair.md` 순서대로(디딤선·난간 CIR → 보행선 DIM → 절단선 SYM1 → 화살표 DIM → UP/DN TXT). 승강기 | CIR / DIM / SYM1 / TXT |
| 7 | 위생기구(TOL), 가구·집기(FUR), 상부 벽체선·가상선(HID) | TOL / FUR / HID |
| 8 | 해치: RC 단면은 `SOLID`로 HAT 레이어에. 영역 구분은 HAT1, 바닥 패턴은 PAT | HAT / HAT1 / PAT |
| 9 | 외부 치수(상부·좌측): CEN 끝 + 900·s에 1단, + 400·s마다 다음 단. 안쪽부터 개구부 → 주열·최외벽 → 전체 | DIM |
| 10 | 축 버블: 가장 바깥 치수선 위에 `축열버블-상`/`-좌` 블록을 `-INSERT`로(번호 입력) | DIM |
| 11 | 내부 치수 | DIM1 |
| 12 | 레벨(평면에서는 13단계 실명 아래에 함께 넣는다) | LEV |
| 13 | 실명, 실번호, 천장고(실 중앙, 가운데 맞춤). 평면 레벨은 그 아래 줄 | ROM / LEV |
| 14 | 단면 기호, 입면 기호, 상세 인출 기호, 방위표 | SYM / SYM1 |
| 15 | 지시선과 재료 표기, 일반 문자, NOTES | TXT1 / TXT / REM |
| 16 | 도곽, 표제란(도면명·축척·도면번호) | TIT / TIT1 |
| 17 | 표준 검사 후 저장 | — |

평면 규칙:
- 벽 두께·크기 기준은 SKILL.md '기본 가정'을 따른다.
- 벽 중심선을 CEN에 먼저 긋고, 벽 양면은 중심에서 두께/2만큼 띄워 그린다.
- 개구부로 끊긴 벽은 조각마다 닫힌 `draw_polyline`으로 그린다.
- 벽 해치는 벽을 겹치지 않는 직사각형으로 나눠 각각 `draw_hatch(SOLID)`로 넣는다. 고리 하나로는 넣을 수 없다.

## 입면도

| 단계 | 내용 | 레이어 |
|---|---|---|
| 1 | 축선(상부 표기용) | CEN |
| 2 | 지반선(GL), 층 레벨선 | ELE / LEV |
| 3 | 건물 외곽선 | ELE |
| 4 | 창호 | WIN / DOR |
| 5 | 마감 줄눈, 재료 구분선 | FIN |
| 6 | 재료 해치 | HAT |
| 7 | 치수, 축 버블(상부만, `축열버블-상`) | DIM |
| 8 | 레벨 표기(층별 FL): 치수선 밖, 층마다 `입단면층레벨` 블록(annotation.md) | LEV |
| 9 | 재료 지시선과 문자 | TXT1 |
| 10 | 도곽, 표제란 | TIT / TIT1 |

## 단면도

| 단계 | 내용 | 레이어 |
|---|---|---|
| 1 | 축선(상부 표기용) | CEN |
| 2 | 지반선, 층 레벨선 | ELE / LEV |
| 3 | 절단된 구조체(슬래브·보·벽·기초) | CON |
| 4 | 조적·건식벽 | WAL / WAL1 |
| 5 | 단열재 | INS |
| 6 | 보이는 입면선(절단되지 않은 부분) | ELE |
| 7 | 창호 | WIN / DOR |
| 8 | 마감 | FIN |
| 9 | 구조체 해치 | HAT |
| 10 | 치수, 층고, 축 버블(상부만, `축열버블-상`) | DIM |
| 11 | 레벨: 치수선 밖, 층마다 `입단면층레벨` 블록(annotation.md) | LEV |
| 12 | 실명 | ROM |
| 13 | 재료 지시선과 문자 | TXT1 |
| 14 | 도곽, 표제란 | TIT / TIT1 |

단면 규칙(매뉴얼): 부득이한 경우를 빼고 보는 방향은 아래에서 위로, 우에서 좌로 자른다. 단, 중요한 부분이 있으면 그 부분이 표현되도록 자른다.
