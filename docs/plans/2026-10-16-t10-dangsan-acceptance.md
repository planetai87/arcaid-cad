# T10 · 당산동 기준층 평면의 0-A 통과 시험

사용자 승인 계획(2026-10-16). GstarCAD 2021, A3 1/200, 기존 API·프로파일 유지.

## 목표와 입력

- 원본 `../당산동 숙박시설.dwg`, 비교본 `output/당산동 숙박시설_평면도.dwg`를 보호한다.
- 코어·X축 16개·Y축 4개만 표준 템플릿으로 옮긴 기준 입력을 준비한다. 단위 헤더만 mm로 고치며 좌표는 확대하지 않는다.
- 원본 정밀 축에 비교본을 평행 이동한다(약 +0.037495, -0.324345 mm). 축·구조·기구 편차 상한 0.01 mm.
- 기준 미리보기·선택 핸들/레이어 매핑·코어/축좌표 대조표를 제시하고 사람 확인 후 입력을 고정한다.
- 객실 27개(A25/B2), 욕실·침대·문·창 상세까지 재현한다. 비교본 927개와 옛 기록 943개의 차이는 정보로 보고한다.

## Task 1: 순수 준비·비교 도구

`tools/acceptance/t10_dangsan.py`, `tests/engine/test_t10_dangsan.py`.

- 곡선 변환·변환 배치·독립 형상 비교를 실패 시험부터 구현한다.
- 로컬 스냅샷에서 기준 DXF, 객실/주석 명세, 원본 기반 기대 manifest를 만든다.
- HEO_BATH/BED/DOOR/WIN을 지원되는 기본 객체로 전개한다. ELLIPSE는 오차 0.01 mm 이하 폴리라인. 반복·대칭·회전은 group.place, 양축 반전은 180도 회전.
- `t10-rooms`, `t10-annotations` 요청을 만들고 객체 20000/그룹 깊이 4 상한을 검증한다.
- 문자·치수·버블은 프로파일의 k=200 값을 쓴다. 제공되지 않은 실번호는 만들지 않는다.
- 파일 경로·해시·mtime·스냅샷 출처를 기록한다. 같은 도면 ID를 파일 식별자로 단독 사용하지 않는다.

검증: 준비·정렬·곡선·객실 집계·누락 및 해치 경계 변경 검출 시험, 참조표 검사.

## Task 2: 기준 입력 확인

- 표준 템플릿에 정확한 코어·축 선택 및 표준화를 적용한 새 기준 사본을 만든다.
- 기존 주석 치수·다른 평면·대지·도곽 제외. 형상과 개구부 좌표 보존.
- 기준 표준 검사(위반·미검사 0), 좌표/형상 비교, 미리보기·매핑표를 제시한다.
- 사용자의 기준 입력 확인 후만 Task 3으로 진행한다. 독립 A/B는 서로 다른 도면 ID.

## Task 3: 실제 CAD 재현·보호 시험

`tests/cad/test_t10_dangsan_cad.py`와 로컬 산출물.

- export_snapshot → read_drawing → draw_batch → check_standard → 필요한 보호된 fix → DWG 저장.
- A/B에 같은 기하 명세를 적용하고 핸들·시간·대상 ID를 제외한 형상/속성을 비교한다. 해치 경계 좌표도 비교한다.
- ROM의 정확한 객실(A/B) 문자로 27실 집계. PS·면적 제외. 독립 기대값은 비교본에서 고정한다.
- 같은 op/명세 재전송 skip, 핸들·형상·기존 상태 불변.
- 다른 입력·일부 삭제·문자/레이어/버블 속성 수동 변경을 각각 전용 사본에서 conflict 및 무변경으로 검증한다.
- 기존 Hooks.after_change 실패 주입 → recovered, 핸들·형상 복귀·태그 잔존 없음.
- 원본/비교본 hash·mtime, 사용자 도면 목록·활성·저장 상태 보존.
- 읽기·명세 작성·적용·검사·재전송 시간을 기록한다. 임의 속도 기준 없음.
