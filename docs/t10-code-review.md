# T10 독립 검토와 처리

검토: gpt-6-astra/high, 새 컨텍스트, 읽기 전용. 범위 `3af52ec..074ade6`, 승인 계획·검증 코드·실제 CAD/MCP 증거를 대조했다. Critical 0, Important 3, Minor 0. 최초 판정 With fixes.

## Important 수정

1. 폴리선 bulge를 mm로 비교하고 타원 결과의 bulge·폐합을 놓쳐 허위 통과가 가능했다. 10,000mm 현·bulge 0.009(처짐 45mm), 대각 편차, 타원에 bulge/닫힘 주입 반례를 실패시킨 뒤 고쳤다. 폴리선은 원호 매개변수와 차이 함수의 2차미분 보간 상한으로 실제 곡선 전체의 공간 편차를 제한한다. 원·호도 중심/반경 오차를 합산하고 짧은 호가 거의 원 전체로 바뀌는 경우를 검출한다.
2. 해치 `hatch_style=2`로 섬을 무시해도 통과했다. 섬 채움 설정·경계 역할을 비교하고 섬 무시/외곽 지정 고장을 검출한다. 원본의 default 내부 경계를 엔진의 outermost 경계로 정규화하는 것은 허용한다.
3. 기준 검사의 zip이 초과 객체를 버렸다. 모든 실제 객체를 비교에 포함하고 예상 밖 객체가 있으면 실패한다.

세 항목을 하나의 수정 단계에서 처리했다. 반례 9개를 RED→GREEN으로 확인했으며 순수 시험 26개가 통과했다. 재검토를 중복 요청하지 않고 회귀시험·전체 시험과 실제 저장된 산출물의 강화 재검사를 근거로 판정한다.

실제 산출물에서 손상은 없었다. 타원 81개는 bulge=0, 열린 폴리선이고 해치 36개는 style=0이며 내부 경계가 있는 2개도 정상이다. 비교본에서 고정한 좌표·형상·주석과 작도 명세·기준 입력은 유지했다. 예전 실행 manifest를 `manifest-at-execution.json`으로 보존하고, 원래 비교본 스냅샷에서 해치 설정·경계 역할만 추가한 검증 manifest를 별도로 식별했다. 강화 검사로 기준 DXF/DWG, 실제 A/B/MCP 산출물 모두 다시 통과했다.
