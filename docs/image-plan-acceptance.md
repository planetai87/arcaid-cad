# 이미지 평면도 재작도 통과 시험 (계획 10단계)

계획: 이미지 판독 개선 계획(2026-10-30 승인) 10단계.

상태: **조건부 통과, 2026-10-31.** CAD 적용·표준 검사·원본 대조는 통과했다. 독립 검증점과 비교 기준 시간은 확보하지 못했다(아래 '완료 조건').

## 입력과 사용자 결정

- 입력: 다른 사무소의 손그림 청사진(6층 평면도)을 찍은 사진(2576×1968 px).
  - 원본과 결과 이미지는 커밋하지 않는다.
  - 작업 폴더는 `C:\arcaid\work\accept1`이다.
- 결정:
  - 치수 우선 + 측정 보조. 원본 치수 문자와 실측이 다르면 치수를 따른다.
  - k=100, 해치 없음.
  - 축 이름은 표준 X1~X6 / Y1~Y3이다.
  - 외벽·코어는 RC(CON), 실내는 조적(WAL)이다.
  - 문자는 실명만 넣는다.
  - 외벽은 빗금 띠만 벽으로 본다.
  - 재지 못한 것은 추정으로 그리고, 출처를 '추정'으로 남긴다.
  - 경계 불일치는 확인한 뒤 승인하고 합친다.
  - 판독·검토 에이전트는 Sonnet으로 부른다.

## 시험 중 추가한 도구 (PR로 병합)

- 사진 보정: 닮음 변환에 2차 다항식 휨을 더한다.
  - 치수 연장선을 세로·가로 기준선으로 쓰고, 값을 모르는 선(`=?`)도 받는다.
  - 판별 가능성을 검사한다: 서로 다른 선 수가 차수+1 이상이어야 하고, 조건수도 본다.
- 빗금 벽 면선: profile 넓은 띠의 시작·끝 가장자리(edges)를 쓰고, `--names=바깥/안쪽`으로 기록한다.
  - 가장자리를 찾는 범위는 구간 경계 ±2 px다.
- merge `--accept`: 확인한 불일치 쌍만 승인한다.
- `set-value --box`: 외곽 상자 추정값을 적는다.

## 검토와 최종 대조에서 찾아 고친 것

- 코어 벽 누락: 샤프트(PD·CH) 둘레 벽과 승강기 앞뒤 벽. 판독 에이전트가 놓쳤다.
  - 주 대화가 profile로 재서 `M.*` 관측으로 기록하고, 벽 7개를 보강했다.
- 계단 가운데 벽: 아래 토막이 약 670 mm 짧았다.
  - 면은 실측했고, 끝은 추정값으로 고쳤다.
- 주방 수납장 X 대각선: 틀 밖으로 약 230 mm 나갔다.
  - 원인: 가파른 대각선을 세로선으로 잘랐다.
  - 고침: 가로 틀선으로 자르고, 틀과 칸막이를 넣었다.
  - 첫 적용 도면은 그대로 두고, 새 도면(r2)에 다시 적용했다.

## 그리지 않은 것과 남은 확인

- 그리지 않은 것:
  - 코어 전실·홀 현관문(붙일 벽 없음)
  - 바닥 타일 구역 외곽선
  - 마감 주기 문자
- 사용자 확인이 필요한 것:
  - 다용도실 동벽 창 선 위치(약 95 mm 차이)
  - 화장실 위 짧은 벽 왼쪽 면(약 100 mm 차이)
- 치수와 실측이 달라 치수를 따른 곳:
  - 온실 남측 창: 양 끝을 벽 면에 맞췄다.
  - 방-3 창: 실측 8,440~10,217
  - 방-4/주방 벽: 실측 x 17,410~17,625

## 교훈

- 판독 에이전트는 관측 이름 앞에 영역 이름을 붙여야 merge 때 이름이 겹치지 않는다. plan-reader 지시에 넣었다.
- 대칭 벽과 외벽은 merge 불일치로 많이 나온다. 외벽 면은 주 대화가 한 번에 정하는 편이 낫다. 스킬 절차에 넣었다.
- 판독 에이전트는 코어처럼 이중선·빗금이 엉킨 곳을 놓친다.
  - 복원 검토(plan-reviewer)가 이것을 잡았다.
  - 검토 뒤에도 겹침 그림으로 한 번 더 본다. 주방 대각선은 마지막 대조에서 찾았다.
- 가파른 사선의 끝은 그 사선과 거의 평행한 선으로 자르지 않는다.
- 템플릿으로 만든 새 도면들은 drawing_id가 같다(T10에서도 기록). bind target만으로는 도면을 구분하지 못한다. 적용 전에 list_drawings로 활성 도면을 확인한다.
